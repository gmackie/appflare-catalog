# Attest verifier corresponding source

This release contains the editable Attest Worker, its exact dependency packages, the sources for generated code, the Appflare manifest and a public Wrangler rebuild. The catalog adds a GET endpoint at `/.well-known/attest-source`. Its plain-text response contains the copyright notices, licenses and direct download URL for this version. Each installation can serve that response without secrets.

## Rebuild the published Worker

Use Python 3.11 or later, Node 26.13.1, npm and pnpm 12.21.0. From inside the extracted `attest-verifier-source` directory run:

```sh
python3 rebuild.py --out rebuilt-index.js
```

The command installs dependencies with the Attest pnpm lockfile and the included npm lockfile for Wrangler 4.136.2, then performs an offline Cloudflare deployment dry run. Dependency installation needs access to npm. The original account routes are retained in the source configuration for reproducibility. Appflare installs into the account and origin selected in the manager. The command checks the emitted module against the SHA-256 in `build-inputs.json`. To compare it with an independently downloaded release zip, use `unzip -p attest-verifier-0.0.0-20261123.5de9ae7.zip worker/index.js | shasum -a 256`. The public Worker can be rebuilt without access to the catalog signing key, Cloudflare, or a private build-tool repository.

The `attest/` tree contains every first-party module Wrangler read and the workspace manifests needed for the frozen install. Edit these files to modify Attest. Each `npm/*.tgz` is an exact public registry package including its distributed JavaScript and any shipped TypeScript, source maps, license and README. `packages.lock.json` identifies the package repository, revision and tarball integrity. `build-inputs.json` lists the module paths with positive emitted bytes and their original SHA-256 values within each package. For a modified third-party library, extract its tarball and edit its sources. When a TypeScript source is provided in `upstreams/`, use its package build script to regenerate its ESM output. Copy the modified files under the same package-relative paths into the corresponding installed pnpm package in `attest/node_modules/.pnpm`. Run `python3 rebuild.py --no-install --modified` to build the edited work. The extracted source tree contains the distribution's public notices in the actual Worker entry.

## Proof system sources

The GPC and GPCircuits TypeScript, circuit definitions, circuit parameter input, artifact generation scripts, TypeScript configuration and upstream yarn.lock are under `upstreams/proofcarryingdata--zupass/`. The GPC and Semaphore Circom library versions are in `npm/` with their own license files. The original artifact package in `npm/@pcd--proto-pod-gpc-artifacts@0.13.0.tgz` contains the original verification keys, WASM and proving keys. Nine JSON verification keys enter this Worker. Inspect the artifact package README for the circuits/release relationship and `packages/lib/gpcircuits/README.md` for the upstream build. To export a verification key from its original proving key using snarkjs, run `snarkjs zkey export verificationkey <name>-pkey.zkey verification_key.json`. A new trusted setup produces different keys. Upstream describes these experimental GPC keys as generated by a single author. The Semaphore proof package ships its combined verification keys; its matching circuit source is included under `upstreams/semaphore-protocol--semaphore/`. The Worker uses the Attest verifier's pinned local Groth16 and verification-key shims.

## Install and operate

Install **Attest verifier** from the catalog in an Appflare manager configured for this catalog's public signing key. Use a paid Workers account. The manifest declares two SQLite Durable Objects and the enrollment rate limiter, requires two independent Sepolia HTTPS RPC secrets and an ES256 signing-key set, and prompts for trusted issuer keys and identity provider configuration. Generate a fresh signing-key set locally with `node attest/apps/verifier/scripts/new-result-key.mjs` and enter only the signing-key JSON requested by the installer. Keep that key and RPC credentials private. Configure the verifier URL for your installed origin, allowed browser origins and finality policy. Check `/health`, the well-known source URL, and an end-to-end presentation using your own trust configuration. See the release's catalog operator guide for the field formats and rollout procedure.

## Catalog release job

The recipe is pinned to Attest commit `5de9ae73a2547dc11ba21bd79e8bf3b734670dc7`, packer commit `fdf67cb1c680c11dd2a9c0ddd353d131b2d8c6db` and version `0.0.0-20261123.5de9ae7`. In the unprivileged pack job, use a fresh pinned public Attest checkout and an empty output directory:

```sh
python3 scripts/attest-distribution/release.py build \
  --checkout "$ATTEST_CHECKOUT" --manifest apps/attest-verifier/appflare.jsonc \
  --packer "$APPFLARE_DIR/packages/pack/bin/appflare-pack.js" \
  --out dist/attest-verifier --key-id "$KEY_ID"
```

The recipe checks local package inputs against integrity-checked npm tarballs and checks selected upstream source against locked hashes. It packs the Worker after adding the notice endpoint, verifies the Appflare hashes and upload budget, and independently compares the complete uploaded Worker from Wrangler with the packed zip member before writing the release. Include `attest-verifier-source.tar.gz` as a download on the same release as the signed manifest and zip. The release URL is version-specific. Future source or dependency pins require a new inventory and release URL.
